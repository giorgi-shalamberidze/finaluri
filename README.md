# Tasks

Tasks is a simple Android application for creating and managing a personal task list.

## Features

* View a list of tasks
* Add new tasks with a title and description
* Delete tasks
* Store tasks locally using Room Database
* Keep data after closing and reopening the app

## Technologies

* Kotlin
* XML
* MVVM Architecture
* Room Database
* RecyclerView
* ViewBinding
* Kotlin Coroutines

## About

This project demonstrates the use of MVVM architecture and Room Database to build a simple task management application. It uses local storage to save tasks and follows modern Android development practices.
